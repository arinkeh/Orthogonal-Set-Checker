## Brief Description
Enough about my ephemeral inspiration; what exactly does this code do? What is it about?! Hold your horses!

The ortho_set_checker serves as a screening machine that saves you the time of manually checking if a set of vectors is orthogonal. A set with 2 vectors is probably a piece of cake to do by hand, even 4 vectors. But as the number of vectors in a set increases, the possible pairs increase almost exponentially, making it nearly impossible for you to do, and most definitely inefficient. Higher-level mathematicians probably have programs that do this for them on a higher, more sophisticated level, but you surely don’t have access to that, so take what you have and get what I offer—yes, my _ortho_set_checker_ made in Python. You could use it for taxing homework or as a tool to help with research on how orthogonal vectors can break the fabric of reality and warp all we know to be true (that exists in some universe). 

## Functionality
So how it works is this:
- It asks you for an input; please, enter numbers only, because last time I checked, words don’t form vectors.
- You enter each vector separately, with each number/entry separated by a space. so if your vector is [1, 2, 1], you would enter 1 2 1.
- When you have entered all vectors as prompted, you may enter your one and only word, "done"—banal, I know.
- I perform my magic in the backroom, sweating to run the code in time, and after 5 seconds, you would get the verdict: orthogonal, or not; yes, it takes me 5 seconds to vet orthogonal sets. I have been doing this for 600 years, centuries before Joseph Fourier proponded the concept.
